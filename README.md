# Atlas Offline

An Android workout log. Data stays on the phone (Room), so it works without a network.

## Stack

Kotlin, Jetpack Compose, Room, Navigation

## What you can do

- Log workouts and cardio
- Use templates and a workout calendar
- Track measurements, a plate calculator, and a rest timer

## Run it

Open `AtlasOffline2` in Android Studio and run the `app` module. Minimum Android version is 8.0 (API 26).
